# claude-skills

Claude Code skills by Gigi Sottile (rcp). This folder is `~/.claude/skills`, so every skill here
is live in Claude Code on the machine it's cloned to.

| Skill | What it does | Run with |
|---|---|---|
| `repo-cleanup/` | Audits a repo used as an AI context layer, proposes fixes, applies only approved ones, adds `CLAUDE.md` upkeep rules, commits | `/repo-cleanup` |
| `checklist-generator/` | Builds an evidence-based readiness checklist from a project's history and writes it to Coda | `/checklist-generator` |

To use a skill yourself: copy its folder into your own `~/.claude/skills/`.
